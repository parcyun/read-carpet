# Read Carpet 프로토타입

Node.js 22.13 이상에서 `npm start`를 실행한 뒤 http://localhost:4173 에 접속합니다. 로컬 데이터는 `data/read-carpet.sqlite`에 보관됩니다. 기존 파일은 Git에 포함되지 않습니다.

## 이번 버전

- 캐릭터 취향을 바탕으로 예시 도서를 추천하고, 도서관·미니홈피·책장·꾸미기·예시 상점을 둘러볼 수 있습니다.
- 하루 한 번 출석(5 P)과 책 제목 퀴즈(10 P)를 완료합니다. 행사 참여·문장 사진·도서 구매 인증(40~50 P)은 종류별 하루 1회이며 사진은 크기를 줄여 로컬에 저장합니다. 사진 내용의 진위 확인이나 심사는 하지 않습니다.
- 감상평·독후감(15 P), 한 줄평·댓글과 대댓글(5 P), 좋아요, 키워드 위키와 연결 도서를 제공합니다. 미니홈피의 도서별 점수 및 기록 공개 설정과 소개 문구 복사는 로컬 예시입니다. 링크는 개인 프로필이 아닌 서비스 첫 화면을 엽니다.
- 예시 아레나에서 세 권의 숙련도 합을 비교하고 승패에 따라 선택한 책의 점수 최대 10 P를 예시 상대와 주고받습니다. 승자가 받을 수 있는 상대 점수, 패자가 가진 책별 점수와 사용 가능 잔액으로 이동량을 제한합니다.
- 점수, 횟수, 퀴즈, 인증 기준 및 위키 내용은 추가 논의가 필요한 임시 값입니다. 문장 예시도 책의 원문 인용이 아닙니다.

## 데이터와 제한

로컬 SQLite는 이 컴퓨터의 로컬 서버에서 단일 프로필을 저장합니다. 공개 미리보기에서는 다른 사람의 프로필이 덮어써지지 않도록 각 브라우저의 localStorage를 사용합니다. 브라우저 데이터를 지우면 기록도 사라지고 다른 기기로 동기화되지 않습니다. 예시 독자와의 대결, 좋아요, 포럼, 위키 및 공개 설정은 실제 사용자 간 공유 기능이 아닙니다. 사용자 계정, 실시간 서버, 사진 심사, 결제·실물 배송은 구현하지 않았습니다.

사진은 기기에 저장되므로 개인 정보가 포함된 사진을 올리기 전 내용을 확인하세요. 저장 공간이 부족하면 저장이 실패할 수 있습니다. 본 프로토타입은 외부 공개를 위한 보안 서버로 설계되지 않았습니다.

## 도서관 및 미니룸 에셋 출처

도서관 지도, 미니룸 및 일부 꾸미기 에셋은 [geunssam/read-carpet](https://github.com/geunssam/read-carpet) 프로젝트를 참고해 가져왔습니다. 도서관 중앙 카펫은 브랜드 레드로 수정했습니다. 원본 저장소에는 별도 라이선스 파일이 확인되지 않아 재배포 조건을 확인해야 합니다.

도서관은 카메라를 중심으로 주변 구역의 가구만 결정적으로 그리는 심리스 예시입니다. 화면 밖의 오브젝트는 별도 데이터로 누적하지 않으며, 다시 돌아오면 같은 위치에 나타납니다. 키보드 방향키 또는 화면 방향 버튼으로 이동하고 서가를 누르면 도서 목록이 열립니다. 미니홈피의 방문록과 공개 설정은 현재 기기에서만 동작합니다.
도서 검색은 현재 로컬 예시 도서를 네 권씩 이어서 표시합니다. 제공된 도서를 모두 보여준 뒤에는 목록 끝을 안내하며, 외부 도서 API와 연결된 무제한 검색은 아닙니다. 프로필 방문록과 미니룸도 로컬 예시입니다.

도서 표지는 예시 판본의 교보문고·YES24·영풍문고 상품 이미지 주소를 직접 연결합니다. 상품 출처는 도서 상세에서 확인할 수 있습니다. 외부 서버의 정책이나 네트워크 상태에 따라 표지가 표시되지 않을 수 있으며, 이미지 이용 허락은 별도 확인이 필요합니다.
