# Read Carpet 프로토타입

로컬 전용 독서 커뮤니티 시제품입니다. Node.js 22.13 이상이 필요합니다.

```sh
npm start
```

브라우저에서 http://localhost:4173 을 엽니다. 데이터는 `data/read-carpet.sqlite`에 저장되며 같은 컴퓨터의 모든 브라우저가 한 프로필을 공유합니다. 파일을 백업하면 데이터를 보존할 수 있습니다. 외부 공개용 서버가 아닙니다.

## 구현 범위와 남은 작업

- 캐릭터 일곱 항목, 서버 내 취향 계산, 8권의 샘플 도서, 추천 카드, 로컬 미니홈피, 도서 검색 및 게시글, 관심 도서와 진도, 상점, 예시 대결과 제휴 이벤트 화면을 제공합니다.
- 캐릭터와 책 표지는 외부 에셋이 아닌 자체 CSS 임시 그림입니다. 제공된 로고와 Unsplash 이미지를 사용합니다. 실서비스 전 사진의 라이선스와 출처를 다시 확인해야 합니다.
- 책에 적힌 문장은 원문 인용이 아닌 창작 예시입니다. 좋아요 수와 대표 독자는 고정 예시이며, 게시글은 로컬에서만 보입니다. 답글·실시간 사용자·실제 결제 및 배송은 구현하지 않았습니다.
- 예시 아레나는 선택한 세 권의 내 숙련도 합과 고정 상대 점수를 비교하며, 보유 포인트가 변경됩니다. 실제 사용자 간 도서별 점수 이전은 구현하지 않았습니다.
- 포인트는 초기 체험용 120점과 진도, 구매, 예시 대결을 반영한 사용 가능 잔액입니다. 누적 총 숙련도와 별도 정산은 후속 구현이 필요합니다.
- 광장 이동은 방향키 또는 터치 버튼으로 하고 서가를 직접 눌러 엽니다. 캐릭터와 서가의 충돌·접근 판정은 아직 없습니다.
- Google Fonts와 Unsplash 이미지는 네트워크가 필요합니다. 다크 화면 전환은 임시 화면 설정으로 새로고침 시 초기화됩니다.

## 공개 미리보기

공개 배포에서는 방문자별 데이터가 각 브라우저의 localStorage에만 저장됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다. 로컬 실행은 기존 SQLite를 사용합니다. 도서 취향 분류는 `/api/recommend` 서버 함수에서 계산합니다.
